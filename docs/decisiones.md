# Bitácora de decisiones

Registro de las decisiones técnicas del proyecto: qué opciones evalué, cuál elegí y por qué.

## 001 — [Nueva App de finanzas]

- **Fecha:** 2026-10-02
- **Contexto:** ¿Qué problema tenía que resolver?
                Simplificar la manera de anotar y comparar gastos e ingresos de un mes para un mejor control economico.
- **Opciones evaluadas:** ¿Qué alternativas había?
                        Ya hice una version con un App Script de Google para automatizar el cargar los datos en una hoja de calculo.
- **Decisión:** ¿Qué elegí?
                Elegí mejorar esa misma idea haciendo una app funcional donde mis finanzas queden registradas en una base de datos y sea facil de cargar y comparar.
- **Por qué:** ¿Qué me hizo elegirla?
                El resolver mi problema de control economico y saber en total lo que ingresa y lo que gasto
